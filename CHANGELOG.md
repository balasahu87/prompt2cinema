# Changelog

## v0.1.0 — 2026-10-05

- Initial public release of **prompt2cinema**
- LLM-style prompt enhancement (offline heuristics + optional OpenAI-compatible API)
- Agentic storyboard / shot planner with VFX + audio intents
- Local procedural cinematic renderer + bundled ffmpeg encode (720p–8K presets)
- Synthetic ambience audio muxed to AAC
- CLI, smoke test script, GitHub Actions CI
